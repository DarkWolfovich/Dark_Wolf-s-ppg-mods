RE_PPG Installation Guide:
1. Download RE_PPG-Installer.exe from Releases
2. Make sure People Playground is completely closed
3. Run the installer. If the game directory isn't detected automatically, specify your game's root folder using 4. "Locate PPG"
5. Click "Install"
6. Launch the game

How install mods
1. Open People Playground folder
2. Create "Mods" folder
3. Place mods there

Downloading mods from unverified sources is not safe. It could give your computer cancer, and then it will explode.
